생기부 세특 연계: 중력 슬링샷 학술 원리

1. 만유인력의 법칙 & 수치 해석 (Euler-Verlet Algorithm)

본 게임 시뮬레이션은 뉴턴의 만유인력 법칙을 기반으로 매 프레임($\Delta t$)마다 탐사선에 작용하는 알짜 가속도를 계산합니다.

F = G * (M * m) / r² → a = ∑ G * M_i / r_i² * u_vector

속도 베를레(Velocity Verlet) 수치적 미분방정식 근사 기법을 사용하여 미세 시간 동안의 위치 변화를 안정적으로 연산합니다.

2. 중력 슬링샷 (Gravity Assist / Swing-by) 메커니즘

움직이는 행성의 중력 우물(Gravity Well)에 접근할 때, 탐사선은 행성의 공전 운동 에너지를 일부 전달받아 연료 소비 없이 속도 벡터의 방향과 크기를 극적으로 변환합니다.

3. 생활기록부 작성 추천 키워드 및 작성 예시

  • 핵심 키워드: 만유인력 수치 해석, Velocity Verlet 알고리즘, 궤도 궤적 예측, Vector Dot/Cross Product, 중력 섭동.
  • 세특 작성 예시: "물리학I 과목에서 배운 만유인력 개념을 바탕으로 JavaScript HTML5 Canvas 기반의 '중력 슬링샷 우주 탐사 시뮬레이터'를 직접 제작함. Euler 및 Verlet 수치해석 방법을 비교하며 연산 오차를 최소화하고, 실시간 중력장 벡터필드 시각화 알고리즘을 구현함..."
